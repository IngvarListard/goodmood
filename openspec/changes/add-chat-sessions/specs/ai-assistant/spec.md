## ADDED Requirements

### Requirement: Chat sessions with full-session context

Чат ассистента SHALL быть разделён на сессии-разговоры: каждое сообщение (`ai_chat_messages`) принадлежит сессии (`session_id`). Текущей сессией пользователя SHALL считаться сессия с максимальным `session_id` (отдельный указатель не хранится). Модель при ответе SHALL получать контекст текущей сессии целиком: system-контекст (роза ветров + записи + свои инсайты), ВСЕ сообщения текущей сессии в хронологическом порядке и новое сообщение пользователя (без ограничения на количество сообщений; compact истории — отдельный будущий change). История прошлых сессий SHALL сохраняться в БД и не смешиваться с текущей.

#### Scenario: Полный контекст сессии

- **GIVEN** в текущей сессии 20 сообщений
- **WHEN** пользователь отправляет 21-е
- **THEN** модель получает все 20 предыдущих сообщений сессии + system-контекст + новое сообщение
- **AND** ответ учитывает начало разговора (не только последние 8 сообщений)

#### Scenario: Сессии не смешиваются

- **GIVEN** пользователь начал новую сессию
- **WHEN** отправляет сообщение
- **THEN** модель получает только сообщения новой сессии, а не прежних

### Requirement: New chat session

В шапке ассистента SHALL быть кнопка «новый чат». `POST /ai/chat/new` SHALL создавать новую сессию (следующий `session_id` для пользователя) и возвращать свежую панель чата: пустая история, composer готов к вводу. Предыдущая сессия SHALL сохраняться в БД без изменений. Подтверждение перед созданием не требуется (действие не разрушающее).

#### Scenario: Начать новый чат

- **GIVEN** в текущей сессии есть сообщения
- **WHEN** пользователь нажимает «новый чат»
- **THEN** панель чата свапается на пустую без перезагрузки страницы
- **AND** следующее сообщение принадлежит новой сессии
- **AND** сообщения прежней сессии остались в БД

#### Scenario: Новый чат с пустой текущей сессией

- **GIVEN** текущая сессия не содержит сообщений
- **WHEN** пользователь нажимает «новый чат»
- **THEN** панель остаётся пустой (допустимо создание новой сессии)
