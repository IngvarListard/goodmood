## MODIFIED Requirements

### Requirement: Chat history inside modal

История сообщений SHALL рендериться в скроллируемой области модалки: сообщения ассистента — слева, тёмный bubble с иконкой-аватаром; сообщения пользователя — справа, bubble с градиентной заливкой. История загружается при открытии модалки (переиспользование `GET /ai/chat`) и SHALL содержать только сообщения **текущей сессии** чата пользователя (полный список сессии, не последние N). Отправка через `POST /ai/chat` обновляет фрагмент `#chat-response` (data-testid сохраняется). В шапке модалки рядом с закрытием SHALL быть кнопка «новый чат»: `POST /ai/chat/new` начинает новую сессию и свапает панель на пустую историю (см. `ai-assistant` «New chat session»).

#### Scenario: History renders on open

- **GIVEN** у пользователя в текущей сессии есть сохранённые сообщения чата
- **WHEN** модалка открывается
- **THEN** история видна: assistant слева, user справа с градиентным bubble
- **AND** сообщения прошлых сессий не отображаются

#### Scenario: Full session history

- **GIVEN** в текущей сессии больше 8 сообщений
- **WHEN** модалка открывается
- **THEN** видны все сообщения сессии, а не последние 8

#### Scenario: Send message updates history

- **WHEN** пользователь отправляет сообщение через composer
- **THEN** фрагмент сообщений обновляется без перезагрузки страницы (htmx)

#### Scenario: New chat button

- **GIVEN** открыт ассистент с непустой историей
- **WHEN** пользователь нажимает «новый чат»
- **THEN** панель свапается на пустую историю
- **AND** прежние сообщения не удаляются из БД
