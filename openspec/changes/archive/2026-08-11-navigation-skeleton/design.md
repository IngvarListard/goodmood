## Context

Приложение «Дневник настроения» построено на Clojure (ring + reitit + hiccup2 + htmx) с Tailwind v4 (browser CDN) и DaisyUI 5. Текущая архитектура: routes → domains → db, результат рендерится в views. Каждая страница сама формирует html/head/body. Единственный экран — `app.views.entries/page`, который оборачивает форму и список записей.

Нет компонента навигации, нет общего layout. Это блокирует добавление новых экранов (дашборд, чек-ин, статистика и т.д.).

## Goals / Non-Goals

**Goals:**
- Единый layout-компонент для всех страниц: html/head/body + навигация + контент.
- Компонент навигации с двумя вариантами (:mobile bottom bar, :desktop sidebar) из одного источника данных.
- Self-hosted SVG-иконки через мемоизированный загрузчик.
- CSS media query для переключения mobile/desktop без JS.
- Существующая страница entries использует общий layout без изменения бизнес-логики.

**Non-Goals:**
- Роутинг и реальные переходы между экранами.
- Реальные экраны (чек-ин, лекарства, давление и т.д.).
- Состояние приложения, backend-эндпоинты.
- JS-детекция ширины экрана.
- Сборка/бандлинг фронтенда, новые зависимости.

## Decisions

**1. Единый nav-items в navigation.clj, а не в layout.clj.**
Навигация — отдельный компонент. Layout просто встраивает его. Это позволяет тестировать навигацию изолированно.

**2. Variant :mobile | :desktop передаётся аргументом, а не определяется внутри.**
Компонент не знает про breakpoint — только рендерит разметку. Layout вешает hidden/md:flex/md:hidden. Это упрощает тестирование и переиспользование.

**3. Иконки загружаются через slurp + memoize, вставляются через hiccup2.core/raw.**
Нет :raw элемента в hiccup2 — используем `(raw "<svg>...")`. Мемоизация — `memoize` на уровне загрузки файла. Неизвестная иконка/вариант — ex-info.

**4. CDN-скрипты вынесены из entries/views в layout.**
Убираем дублирование URL. Layout — единственное место, где объявляются htmx, hyperscript, Tailwind, DaisyUI.

**5. Активный пункт: solid-иконка, неактивные: outline.**
Соответствует скриншотам-референсам (dashboard: home = solid blue, остальные outline gray).

## Risks / Trade-offs

- [Hiccup2 raw] → Проверено: `(raw svg-string)` работает в hiccup 2.0.0. Если версия изменится — проверить совместимость.
- [Memoize] → Если файл иконки изменится во время разработки (hot-reload), кеш не сбросится. Для продакшена это не проблема.
- [Оба варианта в DOM] → Два nav-элемента в DOM одновременно. Скрытые через CSS — нет влияния на производительность.
