# Proposal: redesign-feed

## Why

Дизайн-референс `design/lenta.html` задаёт новый облик главной страницы-ленты: вертикальный timeline с точками состояния, чипы метрик с иконками, цветные state-бейджи, карточка «Как ты сегодня?» с иллюстрацией для empty state, пилюля активного периода с градиентом, AI-инсайт-карточка с графиком по неделям. Текущая лента (`views/feed.clj`) использует generic daisyUI-карточки: строка «энергия 4 · тревога 7 · фокус 3» текстом, state как `badge-secondary`, empty state текстом. Требует `redesign-tokens` (палитра, `.gm-*` классы уже на месте).

## What Changes

- **Timeline-компонент** (`views/feed.clj`, новый приватный/отдельный компонент): вертикальная линия `border`-толщины слева, на каждый день — точка-цвет по state (danger/ok по state_label) на линии, дата-заголовок, карточки записей смещены вправо. Заменяет текущий вывод `compact-card` в секциях дней.
- **Карточка записи**: state-бейдж через `.gm-badge-danger`/`.gm-badge-ok` (норма/спокойствие → ok, тревога/низкое → danger, остальное — нейтральный `bg-base-300`), время + иконка «⋯» справа, метрики — чипы `.gm-chip` в grid-cols-3 с иконками и цветами метрик (`--gm-metric-*`).
- **Empty state**: карточка с SVG-иллюстрацией «улыбчивый контур» из макета (акцентный stroke `--color-primary`), заголовок «Как ты сегодня?», подсказка, full-width primary-кнопка «Создать запись» с круглым белым плюсом.
- **Активный период**: градиентная пилюля `.gm-gradient` с иконкой вместо текущего `active-indicator`-стиля; кнопка «Закрыть период» — outline.
- **AI-инсайт-карточка**: акцентная граница `border-primary/50`, иконка-лампочка в кружке, бейдж уверенности (outline, amber при «средней»), текст совета; график-полилиния по дням недели (7 точек, цвет точки по значению: red/amber/green) для корреляций — на данных существующих AI-секций, без новых запросов.
- **Hero-карточка последней записи**: SVG-роза (`views/rose.clj`) сохраняется, обёртка/шапка приводятся к новому стилю карточки.
- **FAB**: остаётся, приводится к палитре (bg-primary, size по макету 70px → `w-16 h-16` адаптивно).
- i18n: новые ключи для заголовка empty state «Как ты сегодня?» и подсказки — в оба `resources/i18n/{ru,en}.edn`.

## Capabilities

### New Capabilities
- `feed-timeline`: лента отображается как timeline по дням с точками состояния, карточки записи содержат state-бейдж и чипы метрик, empty state — иллюстрированная CTA-карточка.

### Modified Capabilities

_(переуточнение при необходимости: активный период и AI-карточка — визуальный слой существующих секций `/feed`)_

## Scope

- `src/app/views/feed.clj` — основной объём.
- `src/app/views/state_periods.clj` — только стиль `active-indicator`/`start-banner`.
- `src/app/views/ai.clj` — только обёртки/стили секций на feed (ai-correlations → график, ai-advice → инсайт-карточка).
- `resources/i18n/{ru,en}.edn` — новые ключи.

## Non-goals

- Изменение роутов, БД, форматов данных, логики AI.
- Десктоп-версия ленты (контент центрируется `max-w-md`, инерционно наследует стиль).
- Пагинация/подгрузка истории.
- Замена hero-розы на радар из макета (роза — устоявшийся компонент).

## Impact

- **Код**: `src/app/views/feed.clj`, `src/app/views/ai.clj`, `src/app/views/state_periods.clj`, `resources/i18n/{ru,en}.edn`.
- **Миграции/БД/зависимости**: нет.
- **Риски**: hx-boost-навигация и OOB-свапы в секциях AI — проверять каждый htmx-контракт после переработки разметки; SVG-график на отсутствующих данных (пустые недели) не должен рендерить пустоту — показывать fallback-текст.
