# Proposal: add-period-radar

## Why

Радар на ленте (`hero-card` → `rose/radar`) показывает срез **последней записи** — одну точку. Человек с биполярным расстройством смотрит на ленту, чтобы оценить «как я сейчас в целом», а не «чем закончился последний чек-ин». Недавние всплески и спады маскируются одной записью, а длительная картина (неделя, месяц) недоступна вовсе — она есть только на графике настроения-полилинии, где без осей тревоги/энергии/фокуса.

## What Changes

- Радар на ленте отображает **период**, по умолчанию — текущий день: средние значения осей (mood/energy/anxiety/focus) за период
- Крошечные кнопки-переключатели периода: **день / неделя / скользящие 30 дней** (`hx-get` → OOB-свап canvas + подписи, без перезагрузки)
- Агрегация вместо простого среднего: **среднее по дням → взвешивание свежести** (полураспад = период/3; для дня — равные веса). Это убирает два искажения простого среднего: перекос по частоте логирования (тревожные дни логируют чаще) и уравнивание старых записей со свежими
- Пустой период → радар с нулями (по решению владельца), aria-label «нет данных»
- Значения осей — средние непустых значений (nil из записей до миграции 004 не тянут вниз)
- Подпись «среднее с учётом свежести» — честное название формулы
- Точки входа без изменений: радар остаётся в hero-карточке последней записи

## Capabilities

### Modified Capabilities

- `feed-timeline`: hero-карточка рендерит радар за период (день/неделя/месяц) с переключателем, а не только за последнюю запись

## Impact

- `app.domains.entries` или рядом: чистая функция агрегации `entries → {период → оси}` (per-day mean → recency-weighted mean); повторно использует паттерн `week-dates` из feed.clj
- `app.views.feed` / `app.views.rose`: радар-фрагмент с периодом и кнопками; контракт `radar.js` ({labels, values}) не меняется — меняются только данные
- `app.routes.feed`: GET /feed/radar?period=… → OOB-фрагмент
- `resources/i18n/{ru,en}.edn`: подписи периодов и «среднее с учётом свежести»
- Без миграций, без новых зависимостей

## Scope

Радар на ленте с переключателем периода и взвешенной агрегацией.

## Non-goals

- Разброс `±σ` рядом со значением оси (взвешенная дисперсия) — обсудили, взять можно позже
- Рекомендации/инсайты, привязанные к агрегированному состоянию (владелец уточнил: вопрос был про формулу, не про советы)
- График настроения-полилиния (`week-chart`) — остаётся как есть
- Переключение периода без перезагрузки страницы на другие виджеты ленты
