# Proposal: fix-mobile-ux-pass

## Why

На Nothing Phone 1 (viewport 412×915) мобильный UI сломан: нижняя навигация не помещается в один ряд (панель вырастает до 160px и накрывает контент вместе с кнопкой сохранения записи), FAB ассистента (40×40px) частично или полностью перекрыт панелью и физически некликабелен. Отдельно: чат ассистента не показывает отправленное сообщение и состояние «печатает» до ответа LLM (десятки секунд тишины), у e2e-покрытия чата нет быстрого пути без реального API, поле «фокус» спрятано в аккордеон, страницы просмотра/редактирования записей нет, а AI-виджеты ленты имеют три разные кривые анатомии с переносящимся текстом.

## What Changes

- Навигация: «Отметка» → «Запись», перемещение в центр (позиция 3 из 5); RU «Медикаменты» → «Мед», EN → «Meds»; порядок `[Лента, Инсайты, Запись, Мед, Настройки]`
- Высота мобильной панели фиксируется CSS-переменной `--gm-nav-h` (один ряд); паддинг контента страниц считается от неё вместо хардкода `5rem`
- FAB ассистента: 56×56px, позиция `bottom = var(--gm-nav-h) + safe-area + 12px`, `z-60` (выше панели `z-50`)
- Чат ассистента: при сабмите сообщение пользователя появляется мгновенно (оптимистичный бабл), инпут очищается, показывается индикатор «печатает» (три анимированные точки, по макету `design/assistant.html`); серверный свап `#chat-response` заменяет фрагмент; индикатор снимается при ошибке запроса
- E2E: env-флаг `GOODMOOD_FAKE_AI=1` — детерминированные canned-ответы `call-chat` по модели (без сети); быстрый e2e-спек чата (оптимистичный UI + typing) без тега `@ai`
- Чек-ин: «фокус» переносится из аккордеона опциональных в ядро (слайдер после тревоги)
- AI-кластер ленты: единая анатомия карточек для ярлыка/корреляций/советов/novel — тип находки + дот-шкала уверенности (вместо текстового бейджа) + dismiss в одну строку шапки, текст с ограничением строк, иконочные действия; фикс `confidence-badge` при nil (сейчас рендерит `{Missing key …}`)

## Capabilities

### New Capabilities

(нет — все изменения внутри существующих способностей)

### Modified Capabilities

- `ui-shell`: мобильная навигация — новые подписи, новый порядок с «Записью» в центре, фиксированная высота панели и переменная `--gm-nav-h`, паддинг контента от переменной
- `assistant-modal`: FAB — размер 56px, позиционирование и z-index относительно панели
- `ai-assistant`: чат — оптимистичное отображение сообщения и индикатор «печатает»; отображение AI-находок на ленте — единый блок с дот-шкалой уверенности
- `check-in-form-visual`: «фокус» — обязательный слайдер ядра, вне аккордеона
- `dev-env`: детерминированный тест-дабл AI через `GOODMOOD_FAKE_AI=1`

## Impact

- Код: `src/app/views/{navigation,layout,assistant,ai,check_in,feed}.clj`, `src/app/domains/ai.clj` (canned-ответы), `resources/i18n/{ru,en}.edn`
- E2E: `e2e/playwright.config.ts` (env), `e2e/tests/assistant-modal.spec.ts` (+спек чата), правки текстовых селекторов в существующих AI-спеках (переименование кнопок/бейджей)
- Контракты e2e (`data-testid`) сохраняются; текстовые локаторы фидбек-кнопок меняются
- Без миграций БД, без новых зависимостей

## Scope

- Только перечисленные UX-правки мобильного прохода; десктоп не ломаем (панель и FAB — mobile-only)
- Мок AI — только для e2e/dev без ключа; реальный путь OpenRouter не меняется

## Non-goals

- CRUD записей (страница списка/редактирования/удаления) — отдельное изменение `add-entries-crud`
- Потоковый (streaming) ответ чата, серверные push-уведомления о «печатает»
- Редизайн ленты вне AI-кластера, пиксельная сверка со скриншотами
- Изменение soft-mode логики (Decision 14.4 остаётся: фокус скрывается в мягком режиме)
