# Change: Ввод и отображение сна как «чччм» вместо дробных часов

## Why

Поле сна на чек-ине и в edit-форме просит дробное число («7.5»), непонятное
пользователю. Нужно, чтобы сон вводился как время (7 часов 30 минут) и
отображался в понятном формате «7ч30м» — в том числе legacy-значения с шагом
0.1 (7.2 → «7ч12м»). Хранение в десятичных часах (SQLite REAL) остаётся —
весь обсчёт (AI-корреляции, средние) уже корректен, менять схему не нужно.

## What Changes

- Ввод сна на чек-ине и в edit-форме `/entries/:id`: вместо
  `<input type="number" step="0.1">` — два поля: часы (number 0–24) +
  минуты (select с шагом 15: 0/15/30/45), daisyUI join.
- Серверная конверсия: опциональный параметр `sleep_minutes` объединяется с
  `sleep_hours` → десятичные часы (`h + m/60`); оба пусты → nil. Обратная
  совместимость: одиночный числовой `sleep_hours` (API, тесты) работает как раньше.
- Отображение сна везде (feed-карточка, item-фрагмент, карточка записи) —
  «7ч30м» вместо «7.5 ч»; общий форматтер, локализованные единицы (ru/en).
- Prefill edit-формы: часы → ч + мин (остаток × 60 округляется к ближайшим 15
  для select — legacy 7.2 → 7ч15м при сохранении из edit-формы).
- AI-промпты не меняются (продолжают получать десятичные часы «сон=7.5ч»).
- e2e-хелпер `submitEntry` (e2e/helpers.ts) адаптируется под новые поля.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `entries`: требование «Optional blocks as DaisyUI collapses» (сценарий
  «Sleep block») — ввод сна как часы + минуты (шаг 15) вместо number step 0.1;
  валидация принимает опциональный `sleep_minutes`.
- `entries-crud`: требование «Карточка записи с редактированием» — поле сна в
  edit-форме как часы + минуты, отображение в формате «7ч30м».

## Impact

- `src/app/views/check_in.clj`, `src/app/views/entries.clj` — ввод и дисплей
- `src/app/views/feed.clj` — дисплей
- `src/app/domains/entries.clj` — конверсия h+мин → десятичные часы (схема + create/update)
- `resources/i18n/{ru,en}.edn` — ключи единиц («ч», «м»), label «Сон (часы)» → «Сон»
- `e2e/helpers.ts` — заполнение sleep_hours
- Тесты: существующие (числовой sleep_hours) живут; добавить кейсы h+мин и форматтер
- Без миграций: схема БД не меняется

## Scope

- Все точки ввода сна (check-in, edit-форма) и все точки отображения (feed,
  item-фрагмент, карточка /entries/:id).
- Конверсия на границе route/domain; форматтер дисплея с локализацией.

## Non-goals

- Миграция схемы на INTEGER-минуты (нет функционального выигрыша).
- Слайдер/`<input type="time">` для ввода сна.
- Гранулярность минут мельче 15.
- Изменение AI-промптов и формата сна в них.
