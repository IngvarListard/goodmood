# Proposal: entry-actions-from-feed

## Why

На ленте у каждой карточки записи справа стоит иконка-меню (`ellipsis-horizontal`), но она
нефункциональна — это заглушка. Чтобы поправить или удалить запись, пользователь вынужден уходить
на `/entries`, затем на `/entries/:id`. Мёртвый элемент UI вводит в заблуждение, а лишние переходы
замедляют рутинную правку дневника.

## What Changes

- Меню карточки ленты: клик по трёхточечной иконке открывает daisyUI dropdown с пунктами
  «Править» (ссылка на `/entries/:id`) и «Удалить» (открывает confirm-`<dialog>`).
- Удаление прямо с ленты: htmx `DELETE /entries/:id?from=feed`, карточка исчезает in-place без
  перезагрузки; если записей за день больше не остаётся — секция дня удаляется OOB-фрагментом.
- Поведение удаления на `/entries/:id` сохраняется: htmx-ответ по-прежнему `HX-Redirect /entries`.
- Никакого сырого JavaScript — только htmx/hyperscript; переиспользован паттерн
  `app.views.entries/delete-modal`.

## Capabilities

### Modified Capabilities

- `feed-timeline`: карточка записи получает рабочее меню действий (правка/удаление) и in-place
  удаление с исчезновением пустой дневной секции.
- `entries-crud`: поток удаления получает вариант «из ленты» (in-place); поведение удаления со
  страницы `/entries/:id` (переход на `/entries`) сохраняется.

## Impact

- `src/app/views/feed.clj` — `entry-card` (dropdown + confirm-dialog, id карточки),
  `timeline-day`/`past-day-section` (id дневной секции), `today-section` (id секции дня).
- `src/app/routes/entries.clj` — `delete-entry` различает источник по `from=feed` и умеет
  возвращать OOB-фрагмент удаления пустого дня.
- `resources/i18n/{ru,en}.edn` — только недостающие ключи (например aria-label меню); остальные
  тексты переиспользуются.
- Без миграций БД, без новых зависимостей; владение и схема данных не меняются.

## Scope

- Действия на карточках ленты (прошедшие дни и остальные записи сегодня), подтверждающая модалка,
  in-place удаление и OOB-удаление пустой дневной секции.
- Существующая страница `/entries/:id` (edit + delete) не меняется.

## Non-goals

- Inline-форма редактирования прямо в ленте (правка только переходом на `/entries/:id`).
- Меню действий на странице списка `/entries` (только карточки ленты + существующая страница
  `/entries/:id`).
- Массовые действия (удаление нескольких записей, групповые операции).
