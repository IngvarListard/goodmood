# Redesign: верх ленты + модалка ассистента

## Why

Верхняя зона `/feed` выглядит сыро: уведомления залиты сплошным насыщенным цветом (`alert alert-info`), один и тот же совет дублируется в двух местах (внутри вечерней сводки и в виджете инсайтов), чат встроен в тело ленты нелогичной кнопкой и инлайн-панелью, плюс рядом висит лишняя FAB «+», дублирующая вкладку «Отметка». Референсные макеты `design/lentagem.html` и `design/assistant.html` задают целевую визуальную систему — их нужно адаптировать, не переписывая с нуля.

## What Changes

- **Верх ленты — три компактные карточки** вместо сплошных alert-заливок:
  1. Карточка статуса периода: градиентный pill состояния + дата + outline-кнопка «Закрыть период» (рестайл существующей пилюли).
  2. Тонкий баннер «Сводка на завтра готова»: тёмный фон, левая акцентная полоса, крестик dismiss — вместо `alert alert-info`. Из баннера убирается встроенная карточка инсайта (дубль) — совет живёт только в карточке №3.
  3. Карточка совета для состояния: левая акцентная полоса, иконка-лампочка, крестик dismiss, «посмотреть полностью» (collapse для длинного текста).
- **Чат убран из тела ленты полностью** — ни кнопки «Чат», ни инлайн-панели.
- **FAB «+» убрана** с `/feed` (дублирует вкладку «Отметка»).
- **Новая плавающая кнопка ассистента** (единственная FAB, правый нижний угол, над нижней навигацией): круглая, градиент, иконка чат-пузыря с искрой. Открывает глобальную **bottom-sheet модалку ассистента**.
- **Модалка ассистента**: drag-handle (визуальный), шапка «Ассистент / AI-помощник · на основе твоих записей», скроллируемая история (assistant слева, user справа с градиентным bubble), закреплённый composer в flex-низу (не абсолютное позиционирование), дисклеймер — мелкий текст над полем ввода (вместо блока с кнопкой «Продолжить» при первом открытии).
- **Косметический проход** по медикаментам и настройкам в рамках той же системы (pill-кнопки приёмов, карточки) — без изменения поведения.
- Вся разметка — только через токены тем (`base-*`, `gm-*`), никаких новых хардкод-hex поверхностей: обе темы (тёмная/светлая) продолжают работать. Тюнингуем визуал на тёмной.

## Scope

- `/feed`: верхняя зона (период, сводка, совет), удаление инлайн-чата и FAB «+», новая FAB ассистента.
- Новый компонент модалки ассистента (в layout — глобально).
- `/medications`, `/settings`: визуальная полировка в новой системе.
- `/insights`, `/check-in`: только проверка соответствия (уже редизайнены), точечные правки если выпадают из системы.

## Non-goals

- Изменение бизнес-логики, эндпоинтов (кроме вывода из использования `POST /ai/chat/disclaimer` — сам эндпоинт не удаляется), структуры данных, миграций.
- Light-тема как отдельная задача дизайна — но ломать её нельзя (см. токены).
- Десктоп-перепланировка: сайдбар и PageShell не трогаем, только адаптация новых компонентов (FAB и модалка не должны ломать десктоп).
- Анимации сверх стандартных DaisyUI-переходов; жестовые свайпы (drag-handle только визуальный + клик/скрим/Esc).
- Радар-график (rose) и week-chart: остаются как есть, меняется только обёртка-карточка.

## Capabilities

### New Capabilities

- `assistant-modal`: глобальная bottom-sheet модалка AI-ассистента, открываемая единственной FAB: шапка, история сообщений, закреплённый composer, дисклеймер-строка, crisis-guardrail и graceful-fallback внутри модалки.

### Modified Capabilities

- `entries`: удалено требование FAB «+» на /feed (функция покрыта вкладкой «Отметка»); вечерний баннер сводки — тонкий акцентный баннер без сплошной заливки и без встроенного дубля совета.
- `feed-timeline`: пилюля периода → карточка статуса периода; AI-карточка совета → карточка с акцентной полосой, dismiss и collapse; верх ленты без сплошных заливок.
- `ai-assistant`: требование дисклеймера меняется — постоянная мелкая строка над composer вместо блока с подтверждением при первом открытии; чат открывается через модалку ассистента, не через инлайн-панель ленты.
- `design-tokens`: новое требование — разметка компонентов использует только токены тем; запрет хардкод-hex поверхностей/текстов вне `gm-*` хелперов.

## Impact

- Код: `src/app/views/feed.clj`, `src/app/views/notifications.clj`, `src/app/views/ai.clj`, новый `src/app/views/assistant.clj` (модалка + FAB), `src/app/views/layout.clj` (подключение модалки), `src/app/views/state_periods.clj` (рестайл индикатора), лёгкий проход `medications.clj` / `settings.clj`.
- Роуты: без новых эндпоинтов; `GET /ai/chat` переиспользуется как источник контента модалки; `POST /ai/chat/disclaimer` перестаёт вызываться (остаётся в коде).
- i18n: новые ключи в `resources/i18n/{ru,en}.edn` (заголовок/подзаголовок модалки, aria-label FAB).
- Иконки: замена FontAwesome-иконок макетов на heroicons из `resources/icons/heroicons` через `app.icons/svg`.
- E2E: обновить смоук-тесты, где есть кнопка «Чат» / инлайн-панель / FAB «+» (`e2e/`).
