# insight-form-visual — Spec Delta

## ADDED Requirements

### Requirement: Дизайн-стиль формы инсайта

Форма нового инсайта SHALL отображаться карточкой (`bg-base-200 rounded-[18px]`) с полями в паттерне: label 14px semibold → инпут `bg-base-300 border border-base-content/15 rounded-xl` с focus-border primary → подсказка 12px muted. Поля: контекст состояния, состояние для подбора (select), категория (select), советы себе (динамические), утверждение о себе.

#### Scenario: Открытие формы

- **WHEN** пользователь открывает `/insights/new`
- **THEN** все поля отрисованы в дизайн-паттерне, фокус на инпуте подсвечивает бордер цветом primary

### Requirement: Динамические советы себе

Добавление/удаление пунктов советов SHALL сохранять существующие htmx-контракты; кнопка «Добавить пункт» — пилюля с иконкой плюс-круг; каждая textarea пункта — в общем паттерне инпута.

#### Scenario: Добавление пункта

- **WHEN** пользователь кликает «Добавить пункт»
- **THEN** новый textarea появляется через htmx-свап, в сабмит уходят все пункты (существующий контракт)

#### Scenario: Удаление пункта

- **WHEN** пользователь удаляет пункт
- **THEN** пункт исчезает через htmx-свап, остальные сохраняют значения

### Requirement: Highlight утверждения о себе

Textarea «Утверждение о себе» SHALL иметь акцентную рамку primary с мягким свечением и пометку «(необязательно)» приглушённым стилем в label.

#### Scenario: Визуальное отличие поля

- **WHEN** форма отрисована
- **THEN** поле утверждения отличается от остальных бордером primary и свечением

### Requirement: Gradient save

Кнопка сохранения SHALL использовать `gm-gradient` (full-width, radius 12px); htmx-сабмит и валидационные ошибки не изменяются.

#### Scenario: Сабмит с ошибкой валидации

- **WHEN** пользователь сохраняет форму без обязательных полей
- **THEN** фрагмент ошибки рендерится в существующую цель (htmx), стили формы не ломаются

### Requirement: Единые стили inline-редактирования

Фрагменты редактирования инсайта (контекст, советы, утверждение) SHALL использовать тот же паттерн инпутов, что и форма создания.

#### Scenario: Inline-редактирование в карточке

- **WHEN** пользователь включает редактирование на странице инсайта
- **THEN** textarea отрисована в том же стиле, htmx-свап сохранения работает
