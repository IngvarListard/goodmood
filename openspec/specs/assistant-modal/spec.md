# assistant-modal Specification

## Purpose

Глобальная точка входа в AI-ассистента: единственная плавающая кнопка (FAB) и bottom-sheet модалка чата, доступная с любой страницы приложения. Заменяет инлайн-панель чата в теле ленты.

## Requirements

### Requirement: Assistant FAB launcher

На `/feed` SHALL быть ровно одна плавающая кнопка — кнопка ассистента: круглая, градиентная (`gm-gradient`), с иконкой чат-пузыря со искрой (heroicons), размером 56×56px, позиционированная над мобильной нижней навигацией с отступом, вычисленным от высоты панели (`bottom: calc(var(--gm-nav-h) + env(safe-area-inset-bottom) + 12px)`), правый край — `right-4`. Кнопка SHALL иметь z-index 60 — выше панели навигации (z-50), чтобы панель не перехватывала клики. FAB для создания записи на странице отсутствует — создание записи доступно только через вкладку «Запись».

#### Scenario: Single floating button on feed

- **GIVEN** пользователь на `/feed`
- **WHEN** страница отрендерена
- **THEN** в правом нижнем углу видна ровно одна круглая градиентная FAB размером 56×56px
- **AND** клик открывает модалку ассистента
- **AND** FAB «+» для создания записи не существует на странице

#### Scenario: FAB не перекрывается панелью навигации

- **GIVEN** viewport 412×915, RU-локаль, мобильная панель навигации видима
- **WHEN** пользователь кликает по FAB
- **THEN** клик обрабатывается (панель навигации не перехватывает pointer events)
- **AND** нижний край FAB выше верхнего края панели навигации минимум на 12px

#### Scenario: FAB does not break desktop layout

- **GIVEN** окно шире breakpoint `md`
- **WHEN** страница отрендерена
- **THEN** FAB остаётся в правом нижнем углу контента и не перекрывает сайдбар

### Requirement: Bottom-sheet assistant modal

Модалка ассистента SHALL быть bottom-sheet: занимает почти всю высоту экрана, под ней затемнённый scrim; сверху визуальный drag-handle (без жестовых обработчиков — закрытие по крестику, клику по скриму или Esc через нативный `<dialog>`/DaisyUI `modal`). Шапка: заголовок «Ассистент», подзаголовок «AI-помощник · на основе твоих записей», крестик закрытия. Модалка глобальна — рендерится в layout, доступна с любой страницы, где есть FAB.

#### Scenario: Modal opens over any page

- **WHEN** пользователь кликает FAB
- **THEN** открывается bottom-sheet модалка со scrim
- **AND** шапка содержит заголовок и подзаголовок
- **AND** drag-handle отрисован сверху и реагирует на клик закрытием

#### Scenario: Modal closes

- **WHEN** пользователь жмёт крестик, кликает по скриму или Esc
- **THEN** модалка закрывается, страница под ней остаётся в текущем состоянии

### Requirement: Chat history inside modal

История сообщений SHALL рендериться в скроллируемой области модалки: сообщения ассистента — слева, тёмный bubble с иконкой-аватаром; сообщения пользователя — справа, bubble с градиентной заливкой. История загружается при открытии модалки (переиспользование `GET /ai/chat`), отправка через `POST /ai/chat` обновляет фрагмент `#chat-response` (data-testid сохраняется).

#### Scenario: History renders on open

- **GIVEN** у пользователя есть сохранённые сообщения чата
- **WHEN** модалка открывается
- **THEN** история видна: assistant слева, user справа с градиентным bubble

#### Scenario: Send message updates history

- **WHEN** пользователь отправляет сообщение через composer
- **THEN** фрагмент сообщений обновляется без перезагрузки страницы (htmx)

### Requirement: Docked composer in modal

Поле ввода SHALL быть закреплено внизу модалки как часть flex-layout (не абсолютное позиционирование поверх сообщений): input/textarea + круглая градиентная кнопка отправки; над composer — постоянная мелкая строка дисклеймера «AI-ассистент не заменяет профессиональную помощь и терапию».

#### Scenario: Composer stays visible while scrolling

- **WHEN** пользователь скроллит длинную историю сообщений
- **THEN** поле ввода и кнопка отправки остаются закреплёнными внизу модалки
- **AND** строка дисклеймера видна над полем ввода

### Requirement: Assistant guardrails preserved in modal

Модалка SHALL сохранять guardrail-поведение чата: crisis-детекция показывает алерт с ресурсами профпомощи, при отсутствии API-ключа или сетевой ошибке показывается фолбэк-пузырь ассистента (не сохраняется в БД).

#### Scenario: Crisis message inside modal

- **WHEN** пользователь отправляет сообщение с признаками кризиса
- **THEN** ответ содержит напоминание о профессиональной помощи

#### Scenario: AI unavailable inside modal

- **GIVEN** `OPENROUTER_API_KEY` не задан
- **WHEN** пользователь отправляет сообщение
- **THEN** показывается фолбэк-пузырь ассистента с сообщением об ошибке
